# Pigeon Pitch

A city pigeon pitches a statue-restoration startup that calls its nightly handiwork a service and bills City Hall for the patina.

## Run it

```sh
python3 main.py
```

By default, this writes the pitch to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to use another output directory.
